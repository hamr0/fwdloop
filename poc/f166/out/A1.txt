Primitive menu (a grant list; a verb not listed does not exist):
- write: Create or overwrite a file with given contents. Never granted to a step whose check reads its reply (softgreen). (class: write)
- edit: Change part of an existing file in place. Never granted to a step whose check reads its reply (softgreen). (class: write)

- grep: Find lines matching a pattern across files. (class: read)
- recall: Search this run's code and markdown files only (its inputs and out folder, .md .js .py .ts); a CSV or Word file is not searched. Returns pointers to the best matches, not their full text. (class: read)

- related: List the files a given code or markdown file imports and the files that import it, in code and markdown files only; a CSV or Word file has none. (class: read)

- compress: Shrink source code: keep each function header and its doc comment, drop the body (or reduce it to a name). Code only — prose and markdown come back unchanged. (class: read)
- peek: Preview a parked item's start and end without loading all of it. (class: read)
- stash: Park a large piece of text outside the prompt under an id, to fetch back later. (class: store)
- addressCells: Read a spreadsheet as cells, each with an address that can be cited. (class: read)
- readDocx: Read a Word (.docx) file's text. (class: read)

- Use stash to park a bulky intermediate result under an id instead of carrying it from step to step; it lasts this run only and each parked item has a size limit.
- Use peek to look at the start and end of something parked with stash without loading all of it.
